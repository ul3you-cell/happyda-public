Noct-Q-Uncensored-Qwen-Image-2.1
在 Mac mini M4（32 GB）上的安裝與使用指南

研究日期：2026-10-06（台北時間） ·  目標機器：Mac mini M4 標準版、32 GB 統一記憶體
一句話結論：在 M4 Mac mini 32 GB 上跑 Noct-Q-Uncensored-Qwen-Image-2.1 有兩條主路徑—— (A) ComfyUI + GGUF（推薦入門、社群資源多）與 (B) Core ML（devin-lai）（Apple 原生；公開基準只測 M5，M4 須自行實測）。 本指南預設走路徑 A。
⚠ 授權與用途注意：Qwen Research License 限非商業使用。 HF repo 已被標 Not-For-All-Audiences，主模型用於生成裸露與成人場景。 商業用途要直接洽阿里拿商用授權；不要以真實人物製作私密或性化影像，尤其不得涉及未成年或未經同意內容。

1. 模型是什麼（30 秒版本）

  • 作者 Noctaluna 把 Qwen/Qwen-Image-2.1 的 transformer 權重改過，產出無需 LoRA 就能生成裸體與成人場景的單檔 checkpoint。
  • HF repo 已標記 Not-For-All-Audiences。
  • 主模型檔：NoctQ_V4_int8_convrot.safetensors（7.3 GB，V4；V3 為舊版同名不同 hash）。
  • 完整圖庫、不同精度（int4 / fp8 / bf16 / fp16）與評測在 Civitai。

不接受這類用途的話，直接跑官方 Qwen/Qwen-Image-2.1 即可，步驟幾乎一樣。

3. 路徑 A：ComfyUI + GGUF（推薦）

3.1 系統需求

  • macOS 15 或更新（ComfyUI 在 14+ 都能跑，15+ 較穩）
  • Python 3.11
  • 磁碟空間：模型本體約 15–20 GB，首次安裝 ComfyUI + 依賴另加 5–10 GB
  • MPS / Metal 自動啟用——M4 內建 GPU 會被 ComfyUI 自動偵測

3.2 安裝 ComfyUI

打開「終端機」（按 ⌘ + 空白鍵 輸入 Terminal）：

# 1. 如果還沒裝 Homebrew，先裝
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. 用 Homebrew 裝 Python 3.11 與 git
brew install python@3.11 git

# 3. 抓 ComfyUI
git clone https://github.com/comfyanonymous/ComfyUI.git
cd ComfyUI

# 4. 建立虛擬環境（建議，避免污染系統 Python）
python3.11 -m venv .venv
source .venv/bin/activate

# 5. 升 pip，裝 PyTorch（Apple Silicon 版）
pip install --upgrade pip
pip install torch torchvision torchaudio

# 6. 裝 ComfyUI 依賴
pip install -r requirements.txt

PyTorch 在 Apple Silicon 上會走 MPS。不要裝 NVIDIA CUDA 版，對 M 系列沒用。

3.3 安裝 GGUF 載入插件

Noct Q 社群有提供 GGUF 版本。要在 ComfyUI 用 GGUF 格式，要裝插件：

cd custom_nodes
git clone https://github.com/leejet/ComfyUI-GGUF.git
pip install -r ComfyUI-GGUF/requirements.txt
cd ../..

3.4 下載模型（總計約 14 GB）

檔案大小放哪
Noct Q 社群 GGUF（Q4 或 Q8，看你記憶體）5–6 GB（Q4） / 7–9 GB（Q8）ComfyUI/models/diffusion_models/
qwen3vl_8b_int8_convrot.safetensors約 8 GBComfyUI/models/text_encoders/
qwen_image_2.1_vae_bf16.safetensors約 0.5 GBComfyUI/models/vae/

下載連結：

  • 社群 GGUF（Noct Q）：huggingface.co/abenzerps/Qwen-Image-2.1-Uncensored-GGUF
  • 官方文字編碼器（Comfy-Org）：下載
  • 官方 VAE：下載

用 huggingface-cli 一次抓完（要在 ComfyUI 資料夾執行）：

pip install -U "huggingface_hub[cli]"
huggingface-cli login   # 貼你的 HF token

# 主模型：Q4 量化（給 32 GB 機剛好）
huggingface-cli download abenzerps/Qwen-Image-2.1-Uncensored-GGUF \
  --local-dir models/diffusion_models \
  --include "qwen-image-2.1-UC-Q4_K_M.gguf"

# 文字編碼器 + VAE
huggingface-cli download Comfy-Org/Qwen-Image-2.1 \
  --local-dir . \
  --include "text_encoders/qwen3vl_8b_int8_convrot.safetensors" \
           "vae/qwen_image_2.1_vae_bf16.safetensors"

mkdir -p models/text_encoders models/vae
mv text_encoders/qwen3vl_8b_int8_convrot.safetensors models/text_encoders/
mv vae/qwen_image_2.1_vae_bf16.safetensors models/vae/

32 GB 統一記憶體：建議 GGUF Q4（約 5–6 GB）給主模型，留更多記憶體給文字編碼器與系統。 要最高品質可選 Q8 或原版 NoctQ_V4_int8_convrot.safetensors（7.3 GB）。

3.5 啟動 ComfyUI

cd ~/ComfyUI
source .venv/bin/activate
python main.py

第一次啟動會在背景跑 pip install 補依賴，看到 To see the GUI go to: http://127.0.0.1:8188 就開瀏覽器（Safari/Chrome）進去。

3.6 載入工作流

兩個方法（選一個）：

  1. 拖拉 JSON：從 HF repo 抓 NoctQ_V4_workflow.json，直接拖到 ComfyUI 視窗。
  2. 用官方模板：在 ComfyUI 視窗的 Workflow → Browse Templates 搜 "Qwen-Image-2.1"，會看到 Comfy-Org 官方 T2I / Edit / 去背（背景移除）三個模板。

官方模板預設用官方 Qwen-Image-2.1。要跑 Noct Q 改兩個 Loader 節點：

  • 把 Load Diffusion Model 換成 Unet Loader (GGUF)，選 Noct Q GGUF
  • 把 CLIPLoader 的類型選 qwen_image

3.7 建議參數

項目推薦值
Samplereuler
Schedulersimple
Steps25（官方模板預設）
CFG1（官方模板預設，跳過 negative pass）
解析度1024 × 1536 直幅（Noct Q 推薦）或 1024 × 1024

想要 negative prompt 生效，CFG 改成 3；速度約慢一倍。

3.8 啟動低記憶體模式（必要時）

如果跑到一半 OOM（記憶體不足被系統殺掉）：

python main.py --lowvram

32 GB 跑 Q4 通常較有餘裕，但模型版本、解析度與同時開啟的程式都會影響記憶體；第一次請以低負載環境實跑確認。

4. 路徑 B：Core ML（Apple 原生；M4 須自行實測）

適合：只用 T2I（不要編輯）、可以接受命令列，且願意在 M4 上自行量測速度與記憶體用量。

4.1 系統需求

  • macOS 15 或更新（必要）
  • Python 3.11、3.12 或 3.13
  • 磁碟空間：模型包 14.74 GB + 依賴與編譯空間

4.2 安裝

git clone https://github.com/devin-lai/Qwen-Image-2.1-Coreml.git
cd Qwen-Image-2.1-Coreml
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 下載預轉好的 Core ML 套件
python download_models.py

第一次跑會編譯 Core ML 模型，較慢；之後會 cache。

4.3 第一次出圖

python generate.py --out neon.png

這會用 repo 內建的 neon 招牌 prompt 出 1024 × 1024 圖，40 steps。預設 cpu_and_gpu（GPU 加速）。

4.4 自訂 prompt

裝可選依賴 + 編碼 prompt 一次：

pip install '.[torch-reference]'
python encode_prompt.py "a lighthouse in a storm, long exposure" --name lighthouse
python generate.py --prompt-embeds assets/prompts/lighthouse.npz --out lighthouse.png

encode 階段會另外下載官方 Qwen3-VL 文字編碼器，記憶體用量可能比生成更高；32 GB 較有餘裕，但仍應以第一次實跑為準。

4.5 M4 實測尚未公開

該專案公開基準只測了 M5 32 GB，FAQ 明寫：M1/M2/M3/M4 還沒正式基準。跑起來建議到 issue 區 填 hardware report 補資料。

5. 怎麼選？

決策樹
第一次跑 Qwen-Image 系列嗎？
  • 是 → 路徑 A（ComfyUI）
    • 要編輯既有圖片？→ 用 Comfy-Org 官方 image_edit 模板
    • 否 → 用官方 t2i 模板
    • 跑得很慢？→ Q4 GGUF；或加 --lowvram
  • 已經會用、想榨效能 → 路徑 B（Core ML）

32 GB 統一記憶體其實很夠。如果跑 ComfyUI 時瀏覽器、Slack 同時在吃 RAM，先用 Q4 GGUF 留 buffer；熟手了再換 Q8。

6. M4 32 GB 額外注意

  • 統一記憶體是共享的：瀏覽器、Slack、VS Code 與圖像模型共用同一池記憶體。跑圖前先關掉重度程式，並以系統實際記憶體壓力為準。
  • MPS 不等於 CUDA：有些 PyTorch op 在 MPS 上可能未實作或較慢。GGUF 是另一種載入方式，不能保證解決每一種 MPS 問題。
  • 不要把媒體引擎當成出圖速度指標：Apple 規格中，M4 為 10 核 GPU、120 GB/s 記憶體頻寬；M4 Pro 為 16 核 GPU、273 GB/s。兩者都有影片媒體引擎，但其規格不能直接換算成圖像生成快多少。
  • Core ML 的 M4 數據仍缺：目前公開基準是 M5 MacBook Pro 32 GB；第一次跑時請記錄相同解析度與 steps 的耗時，再決定是否改走這條路。

7. Prompt 怎麼寫

Qwen-Image-2.1（以及 Noct Q）吃敘述文，不吃 tag 列表。模板：

[構圖/鏡頭] + [主體（含明確年齡）] + [動作] + [場景] + [光線] + [風格]

範例（英文）：

A close three-quarter portrait of a woman in her late twenties sitting on a sunlit balcony, soft morning light, shallow depth of field, photographic style.

進階：

A low-angle wide shot of a man in his early thirties jogging along a wet seaside boardwalk at dawn, orange sodium streetlights reflecting on the puddles, soft mist, cinematic.

範例（中文也支援）：

一張 35mm 街拍：夜晚的香港霓虹巷弄裡一位二十多歲的女性撐著透明傘，雨水在路面反射霓虹色彩，淺景深，菲林顆粒。

8. 疑難排解速查

症狀可能原因解法
ComfyUI 啟動後看不到 GGUF loader沒裝 ComfyUI-GGUF回到 §3.3
出圖全黑 / 全噪訊VAE 沒選對 / 解析度非 32 倍數確認 VAE 檔名、解析度
OOM / 程式被殺統一記憶體被其他程式佔走關其他程式；換 Q4；加 --lowvram
Core ML 報 computeUnits 錯誤macOS < 15升 macOS 或改用路徑 A
PyTorch 報 "MPS backend not available"沒裝 Apple Silicon 版 PyTorchpip install --upgrade torch（不要 CUDA 版）
文字渲染奇怪CFG 太高試 CFG 1（預設）或 2
中文出圖文字糊Q4 量化掉字換 Q8 或原版 int8
