共同 JSON 交卷欄位

欄位用途
role / ticker / security_type識別任務與資產類型
as_of_date / data_timestamp固定資料邊界，避免新舊資訊混用
evidence / source_urls逐項區分 fact、estimate、hypothesis、sentiment、needs_confirmation
confidence / risk_flags / dissent_note保留不確定性與反方意見
position_rec / conclusion_type限定為 entry、hold、watch、trim 或 veto 等標準結論
