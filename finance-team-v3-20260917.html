5. 社交媒體替代來源 (取代 Reddit/Discord 限制)

Reddit/Discord 公開資料難以作為分析使用（多匿名、API 限制多）。X/Twitter (透過 xurl skill) 與 Meta 公開 thread 為實際可用替代：

  • xurl skill：可搜尋 X/Twitter 公開貼文、threads、profile；情緒指標可從 like/retweet 數量化。目前 X API 認證狀態：awaiting auth（NoAuthMethod），完成認證前 X/Twitter 情緒欄位一律維持「待確認」，不虛構貼文或情緒分數。
  • Meta 公開 thread：FB 公開社團與 profile 可用 web_extract 抓取，但需注意隱私與 robots.txt。
  • RSS feeds：competitor-news-monitor + rss-feeds skill 仍為新聞催化主來源。
  • 所有情緒訊號皆標「情緒、非事實」，不得升級為催化劑結論。
